## If go — Handoff to `/speckit-specify`

- **Problem**: 用户在 Windows 上做有时间限制的活动时，需要剩余时间始终悬浮在所有应用之上、余光可读；内置时钟经实测不能置顶、形态臃肿、外观不可接受，现状只能手动切换查看。
- **Chosen approach**: concept.md **Option A——极简置顶悬浮计时器**（appetite: small，数天）；独立单一用途应用，纯本地、无后端、不联网。
- **In scope（首版）**:
  - 始终置顶的小悬浮窗，大号剩余时间，可拖动定位；
  - 最直接的时长设定 + 开始/暂停/重置；
  - 到点归零 + **声音提醒**（2026-09-18 已确认；不做 Toast/闪烁）；
  - 默认外观简洁耐看（"嫌丑会弃用"已被实测证明，故最小视觉打磨在首版内）；
  - 计时基于绝对结束时刻，睡眠/唤醒后剩余时间正确（真机验收）；
  - 断网完整可用。
- **Out of scope（首版排除）**: 多计时器/预设库/番茄循环/统计历史；透明度/点击穿透/贴边吸附；托盘常驻/开机自启/重启恢复；主题系统与外观深度定制；多级提醒与勿扰/全屏/锁屏兜底强提醒；任何网络功能/账号/遥测/自动更新；商店上架与安装包工程；Win10 更旧系统、ARM64、非 Windows 平台。
- **Success metrics（承自 problem.md）**: 运行中被遮挡需切换查看的次数 = 0；因没看到时间而错过节点 ≈ 0；断网下完整流程通过；用户在有计时需求的场次中愿意实际使用。
