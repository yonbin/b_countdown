# Quickstart 验收指南：始终置顶的悬浮倒计时器

**Date**: 2026-09-18 | **Feature**: 001-floating-countdown

本指南用于在实现完成后，端到端验证特性按 [spec.md](spec.md) 与 [窗口行为契约](contracts/window-behavior.md) 工作。它只包含环境准备、命令与**预期观察结果**，不含实现代码。

## 1. 前置条件

- Windows 11（x64 或 ARM64）
- .NET 8 SDK（`dotnet --version` 能显示 8.x）
- 无网络环境也可运行全部验证（验证 FR-016 时主动断网）
- 可选：第二台显示器（多屏/混合缩放验收）、屏幕录制软件（录屏可见性验收）

## 2. 构建与自动化测试

在仓库根目录执行：

```powershell
dotnet restore
dotnet build -c Release
dotnet test tests/Countdown.Core.Tests -c Release
```

**预期**：构建 0 错误；Core 测试全部通过，至少覆盖（对应 [data-model.md](data-model.md) 的迁移表）：

- 开始/暂停/继续：暂停期间剩余冻结，继续后只扣减运行时间（T1–T3）；
- 归零后停在红色 00:00、不正计时（T4）；
- **睡眠模拟**：虚拟时钟向前跳过一段（短于与长于剩余两种），剩余重算误差为 0，跨过结束时刻直接进入 Finished（红色 00:00，T7→T4）；
- 时长解析：`90`/`5m`/`90s`/`1m30s` 合法，空/0/负数/乱码非法（FR-012/FR-013）。

## 3. 运行应用

```powershell
dotnet run --project src/Countdown.App
```

**预期**：冷启动 2 秒内出现一个无边框小悬浮窗，首启位于主显示器右上区域；任务栏有其条目；无控制台窗口、无网络提示。

## 4. 手工验收场景（按优先级）

### S1 — P1：始终可见（对应 SC-001、US1）

1. 在悬浮窗上右键，选择 `10 分钟`（或经"自定义…"设 1 分钟）开始；
2. 切换并最大化编辑器、浏览器等多个普通窗口；
3. 拖动悬浮窗到屏幕不同位置；关闭后重新启动。

**预期**：悬浮窗全程在最上层完整可见、数字逐秒递减；重开后出现在上次关闭的位置。

### S2 — P2：到点视觉终态（FR-007/009）

1. 设 10 秒开始，不做其他操作等待归零；
2. 归零后静置 2 分钟以上，再右键分别验证"重置"与直接点预设重开。

**预期**：归零后两张卡片立即转红、停在 00:00（无文字、不正计时、**无任何声音**）；红色终态持续保持、不自动消失；右键菜单中没有"确认"项；"重置"立即回到待设定状态；直接点预设/自定义则以新时长立即开始（FR-019）。

> 历史说明：S2 原为"到点声音 + 2 分钟自停 + 勿扰复测"，2026-09-19 用户决定移除全部声音能力（见 spec.md Session 2026-09-19），勿扰/静音相关观察项随之作废。

### S3 — P2：睡眠/唤醒（FR-006/009、SC-003，关键真机项）

1. 设 5 分钟并开始 → 立刻让电脑睡眠 → 约 1 分钟后唤醒；
2. 设 1 分钟并开始 → 睡眠 → 3 分钟后唤醒（跨过结束时刻）；
3. 若机型支持，分别在现代待机（S0）与传统睡眠（S3）设置下各做一遍。

**预期**：场景 1 唤醒后剩余约为 4 分钟，与墙上时钟相差 ≤1 秒；场景 2 唤醒瞬间卡片立即转红并停在 00:00（无文字、不正计时、无声音），重置/重开行为符合契约。

### S4 — P3：控制与输入（FR-011/012/013、SC-002）

- 运行中暂停，等现实 10 秒后继续：剩余只减少运行中的时间；
- 右键菜单预设 5/10/25 在两次点击内开始；"自定义…"依次输入 `90`、`1m30s`、`abc`、`0`：前两者正常开始，后两者无法开始并有格式提示；
- 用秒表粗测：从启动到常用预设开始计时不超过 15 秒、预设开始为 2 次点击（右键 + 菜单项）；
- 运行/暂停中右键：菜单中不出现时长设定项；菜单弹出后点别处或 Esc 关闭，计时状态无变化。

### S5 — 录屏可见性（FR-017）

开始一个倒计时后，用普通"显示器/窗口录制"方式录屏 10 秒并回放。

**预期**：录制过程中悬浮窗在录制画面里始终可见；成品中能看到它（"会入镜"为首版明确接受的行为，不是缺陷）。

### S6 — 多显示器 / 高 DPI（FR-018）

把悬浮窗放到不同显示器（含不同缩放比例，如 100% 与 150%）、关闭重开；在窗口位于副屏时关闭副屏（或断开）后再启动。

**预期**：数字在各缩放下清晰不模糊；位置被记住；保存位置已无对应屏幕时回退到主显示器默认位置，不出现窗口消失在屏幕外的情况。

### S7 — 离线与零网络（FR-016、SC-005）

断开所有网络（或飞行模式），完整走一遍：启动 → 设定 → 暂停/继续 → 睡眠唤醒 → 到点红色终态 → 重置。

**预期**：全程无任何功能差异、无网络错误提示。（开发期可用防火墙/抓包工具确认运行期无外联请求。）

### S8 — 单实例与退出（FR-015）

应用运行时再次启动；计时中通过右键菜单"退出"后重新打开。

**预期**：第二次启动不出现第二个窗口（直接退出或激活已有实例）；重开为全新待设定状态，不恢复上次计时，但窗口位置保留。

## 5. 发布产物验证（可选，验收分发形态）

```powershell
dotnet publish src/Countdown.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
# ARM64 设备改用 -r win-arm64
```

**预期**：发布目录得到单个可执行文件；复制到未装 .NET SDK 的干净 Windows 11 环境可直接运行；无安装步骤、无网络首启依赖（程序不包含任何音频资源，2026-09-19 起）。

## 6. 验收判定

- S1–S8 全部观察到预期结果 → 特性满足 spec，可进入任务实施完成判定；
- S3 睡眠项如失败，**不得**降级为"偶现问题"发布——它是 SC-003 与用户信任的核心，须回到 [research.md](research.md) R-2/R-3 检查时间源与 Resume 处理。
